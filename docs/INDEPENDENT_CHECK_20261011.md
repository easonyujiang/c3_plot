## 外部公式与独立实现

[NASA Glenn 理想火箭方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/ideal-rocket-equation/)：

Δv = g₀ Isp ln(M初始 / M结束)。多级相加，计算下级时带上完整上级及额外载荷。

[MIT 轨道与推进课程的 vis-viva / Hohmann 算例](https://ocw.mit.edu/courses/16-851-satellite-engineering-fall-2003/e9e1eb82a6e428358fb07c1ee0fd2c3c_ps2_cg_solution.pdf)：

v = √[μ(2/r − 1/a)]，在燃烧点计算转移前后速度之差。

以三个原基准反算经验损失，另用 Lagrange 插值实现原二次损失模型；未导入项目计算器、拟合器或任务求解器。它验证的是公式实现与数值自洽，三个点恰好重构不等于新增独立飞行验证。脚本：`tools/verify_neutron_independent.py`，结果：`output/independent_check_20261011/verification.json`。

| 原始载荷 / t | 原始剩余 Δv / m/s | 独立重构 / m/s | 反算经验损失 / m/s |
|---|---:|---:|---:|
| 4.000 | 500.0（200 km） | 500.0 | 1727.907 |
| 2.500 | 1581.0（220 km） | 1581.0 | 1666.874 |
| 1.055 | 3162.8（220 km） | 3162.8 | 1643.796 |

4 t 点转换至统一 220 km 参考轨道后剩余 511.826 m/s；不能直接把原始 200 km 点当作 220 km 点。

## 倾角与等效 C3

700 kg、400 × 40000 km、89°，默认发射纬度 19.81°、基准为向东发射。目标 89°可直接进入，不先进入 19.81°再硬做 69.19°在轨变轨；发射方向变化通过自转贡献差异计入上升段预算。基准倾角是现有模型假设，原记录没有额外证据确认真实基准飞行的倾角。

| 项目 | 独立计算 |
|---|---:|
| 抬远地点 | 2514.141 m/s |
| 远地点抬近地点 | 17.326 m/s |
| 发射方向自转修正 | 428.986 m/s |
| 总额外速度需求 | 2960.452 m/s |
| 目标物理 C3 = −μ/a | −15.001334 km²/s² |
| 等效 C3 | −5.667320 km²/s² |
| 独立求最大载荷 | 1198.744 kg |
| 软件任务求解结果 | 1198.374 kg |
| 差值 | 0.370 kg |

等效 C3 = [(v参考圆轨道 + 总额外Δv)² − 2μ/r参考] / 10⁶。它把倾角及多段速度预算折算为参考曲线的对照坐标，不是目标轨道的实际能量。曲线查值仍不能取代点火次数、燃料与分级检查。

同一近远地点改为 19.81°，独立运力约 1539.429 kg，软件约 1539.505 kg；改为 180°，独立约 612.976 kg，软件约 612.715 kg。四组倾角 0 / 19.81 / 89 / 180°均逐项核对速度需求及等效 C3，模型确实使用倾角。

另用最近两个基准点反算上面级剩余燃料，再对剩余燃料作线性插值，得到 1197.439 kg，与原模型相差约 1.305 kg。这是局部模型敏感性对照，不是实飞误差界限。存储曲线经过 C3 / 载荷显示舍入，全部采样点的最大反算差约 0.491 kg。
