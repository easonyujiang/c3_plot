## 数值与界面验证

历史 Neutron 三个基准载荷为 4 / 2.5 / 1.055 t。以 700 kg、400 × 40000 km、89° 为例，现有模型得到约 1198 kg 运力；额外计入 200 kg 整流罩时净运力约 998 kg。独立火箭方程和轨道公式复算相差约 0.37 kg，原结果位于 `output/independent_check_20261011/verification.json`。

700 kg 低于最低基准，因此结果为外推候选，不能因公式复算一致或界面流程通过而标为经过实际飞行验证。旧 UI 验收输入的 4.898 / 1.609 / 1.015 t 同样是模型生成的测试数据，不是新增测量。

本轮之前的完整回归为 935 项通过。旧版 dashboard 专属测试已随旧界面删除，新的测试数量应以本轮执行结果为准。React 工作台的资源路由、实际图表交互、小屏布局、编辑取消与任务查询由当前测试覆盖。

## 仍需验证的内容

- 当前 Neutron 的独立载荷点完整上升段、任务终态与剩余可用推进剂。
- 飞行程序变化、FAR 气动、有限推力、长滑行和蒸发对最大运力的影响。
- Principia 在具体任务中的实际初始化、参考系及多体轨迹。
- 足够多次独立试飞后的重复性和可用于推荐的保守余量。

RealChute 受控实验只在其明确的配置/DLL 指纹与适用范围内有效。环境变化时应保持 unresolved，不能由这些历史记录重新授权。原始证据在 `experiments/control_mass/`，由现有生产门控和回归测试继续使用。
