# 任意地球轨道运力查询模型

## 为什么不能只查 C3

C3 是轨道比能量的表达，无法单独描述倾角，也无法区分“只送入转移椭圆”和“在目标高度完成圆化”。

例如，高度 35,786 km 的圆轨道自身 C3 约为 `-9.455 km²/s²`。顺行、极轨和 180°逆行圆轨道的轨道能量相同，但实际发射所需速度增量明显不同。因此数据库查询使用“参考停泊轨道后的等效剩余 Δv”匹配火箭，C3 只作为辅助显示。

## 35,786 km @ 180°的计算

默认条件：

- 地球两体模型；
- 高度均为海拔高度；
- 初始停泊轨道 220 km；
- 发射场纬度 19.81°；
- 火箭标定基准为从该发射场向东进入约 19.81°停泊轨道；
- 目标为 35,786 km、180°圆轨道，包含目标点圆化。

从纬度 19.81°的发射场不经过狗腿机动能够直接进入的倾角范围为：

`19.81° ≤ i ≤ 160.19°`

所以系统不会错误地从 19.81°直接做 160.19°平面变化，而是采用：

1. 向西发射，进入 160.19°初始轨道；
2. 在 220 km 近地点加速，进入目标高度为 35,786 km 的转移椭圆；
3. 在高点把圆化与剩余 19.81°平面变化合并为一次矢量速度变化；
4. 相对于数据库的顺行标定曲线，补偿向西发射失去的地球自转助推。

这不是一次点火任务。系统把任务拆成三次：进入 220 km 停泊轨道、近地点霍曼转移出发、高点圆化与平面变化。标定曲线已经覆盖第一次点火；因此上面级在停泊轨道之后仍必须能够重启两次。若采用“先圆化、再单独变轨”的保守策略，则会显示为四次总点火、三次停泊轨道后点火。

当前常数下的预算约为：

| 项目 | Δv |
|---|---:|
| 转移出发 | 2,451 m/s |
| 高点圆化与 19.81°平面变化合并 | 1,661 m/s |
| 发射方向/地球自转修正 | 874 m/s |
| 等效总需求 | **4,986 m/s** |

目标圆轨道周期约 23.93 小时，查询等效 C3 约为 `41.94 km²/s²`。这里的“查询等效 C3”只是把总 Δv 映射回原 C3 曲线以便比较，不是目标轨道的物理 C3。

在当前 `calibrated_serial_multiburn` + `whole_burn_per_stage` 模型下，`Neutron I 2630` 对该任务（35,786 km @ 180° combined，2.5 t / 220 km / dv_rem=1581 校准点）的最大可验证载荷约为 **0.502 t**（可行下界 0.5022 t / 不可行上界 0.5028 t，容差 0.001 t，见 `docs/MISSION_CAPACITY_SEARCH.md`）。

注意：

- 这是**模型结果**，不是现实飞行认证值。
- 会随校准点、发动机数据和模型更新而改变。
- 仅适用于本文件明确描述的 35,786 km @ 180° combined 任务参数。
- 该数值由正式搜索器生成（`find_max_payload_for_mission`），不得手工硬编码进业务算法。

## 查询模式

页面预置了四个常用地球任务，便于快速比较：ISS（408 km、51.6°圆轨道）、SSO（600 km、97.8°圆轨道）、GTO（35,786 km、28.5°转移轨道）和 GEO（35,786 km、0°圆轨道）。更特殊的 35,786 km @ 180°逆行圆轨道仍可直接手动输入。

任务规划页支持两种交付方式：

- **目标圆轨道**：包含目标高度圆化，适合“把载荷留在该圆轨道”的任务。
- **转移轨道注入**：只保证进入以停泊轨道为近地点、目标高度为远地点的椭圆轨道，不包含圆化。

可以输入任务载荷。输入后，数据库按“满足任务且剩余运力最少”推荐最合适的火箭；不输入时按该轨道最大运力排序。

## 计算公式

设停泊轨道半径为 `r1`、目标半径为 `r2`，转移轨道半长轴：

`a = (r1 + r2) / 2`

转移轨道两端速度由 vis-viva 方程得到：

`v = sqrt(μ(2/r - 1/a))`

目标点圆化和平面变化使用合并矢量燃烧：

`Δv2 = sqrt(vt² + vc² - 2 vt vc cos(Δi))`

总查询需求（停泊轨道插入由标定曲线覆盖）：

`Δv_query = Δv_departure + Δv_arrival + Δv_rotation`

每枚火箭保存有“载荷—剩余 Δv”曲线。服务端对该曲线反向插值，得到任务轨道的最大载荷，并计算指定载荷的余量与利用率。对于停泊轨道后需要两次或以上点火的任务，服务端还会检查最高级 `multi_ignition` 标志；不支持重启的火箭会保留在结果中用于审计，但不会被标为可行或推荐。

## 适用范围与限制

这是基于实测校准曲线的两体脉冲近似，适合早期任务筛选和不同火箭之间的统一比较。它尚未模拟：

- 有限推力和长时间燃烧造成的重力损失；
- 发射场方位角禁区、落区和狗腿航迹；
- 上面级寿命、推进剂沉降和热控；数据库只用 `multi_ignition` 做“是否允许重启”的一阶筛选，不代表真实的点火次数、间隔或可靠性；
- 月球、行星引力摄动以及精确发射窗口；
- 载荷整流罩尺寸、结构载荷和接口限制。

接近火箭能力边界的任务应保留工程余量，并使用轨道仿真器或 KSP/RSS 实飞结果复核。
