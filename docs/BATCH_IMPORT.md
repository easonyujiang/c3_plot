# 批量导入工作流

任务规划和导入窗口现在使用统一的“预览—确认”导入管线。

## 快速流程

1. 打开“导入配置”。
2. 在“批量导入配置”区域一次选择多个 `.yaml`、`.yml` 或 `.craft`，也可以选择整个 VAB 文件夹。
3. 等待预览完成。系统会逐项显示：可直接导入、待补全、已导入、辅助文件或错误。
4. 保持“允许同名更新”开启时，确认后会更新同名火箭；关闭时同名项目会被保留并报告。
5. 点击“导入可用项目”。所有通过校验的项目会批量计算、写入 SQLite，并同步写入 `rockets/*.yaml`。

`.craft` 通常会被标记为“待补全”，因为存档没有三条性能校准点。可以在该行直接打开草稿编辑器；`.loadmeta` 会自动作为同名 `.craft` 的辅助元数据，不会单独创建火箭；`.craft.original` 会自动忽略。

## 重复与安全

每个来源文件都会计算 SHA-256 并记录在 `import_sources` 表中。相同文件再次选择时显示“已导入”，不会重复创建记录。不同内容但同名的文件会显示为更新候选，只有勾选“允许同名更新”才会覆盖同名火箭。

批量预览接口不会写入火箭数据：

- `POST /api/import/batch/preview`
- `POST /api/import/batch/confirm`

如果需要自动化脚本，可以先调用 preview，保存返回的 `items`，人工或脚本移除 `needs_review` / `error` 项后，再把剩余项目提交给 confirm。

## 发动机组

级段不再限制为单一发动机。导入器会保留 `engine_groups`，例如同一 SSTU 部件的 `Triple` 布局为 3 台，同一级段出现 Merlin 与固体助推器时也会分别记录。计算层按总推力和质量流量合成等效真空/海平面比冲，避免把一个部件误计成一台发动机。

## YAML 兼容

旧版本曾经把 NumPy 标量写成 `!!python/object/apply` 标签。新的 YAML 写出路径只写入普通 Python 数字；读取路径使用不执行 Python 对象的兼容 Loader，只丢弃旧结果缓存中的未知 `dv` 标签，不影响火箭级段和校准数据。
